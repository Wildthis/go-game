# 围棋人机对战 (Python)

一个纯 Python 实现的围棋游戏，支持初级人机对战。

## 功能

- 支持 9×9、13×13、19×19 三种棋盘
- 完整的围棋规则：提子、打劫（Ko）、自杀禁手
- AI 对手具备基础策略：吃子优先、救急、局部战斗
- 命令行界面，带坐标显示

## 快速开始

```bash
# 19路棋盘，难度2（推荐）
python main.py

# 9路小棋盘，难度1（简单）
python main.py 9 1

# 13路棋盘，难度3（较难）
python main.py 13 3
```

## 操作

| 命令 | 说明 |
|------|------|
| `4D` | 在第4行D列落子 |
| `pass` | 放弃一手 |
| `resign` | 认输 |
| `help` | 显示帮助 |

## 技术细节

### 棋盘逻辑 (`board.py`)
- 基于并查集思想的组/气计算
- 完整的提子、打劫、自杀规则实现
- 合法落子点检测

### AI 策略 (`ai.py`)
三个难度等级：
1. **简单** — 随机合法落子
2. **普通** — 评估函数打分，70%最优决策 + 30%随机
3. **困难** — 更精细的评估，加权候选池

评估维度：
- 提子价值（权重最高）
- 气的数量
- 邻近己方/敌方棋子
- 救急（气少的棋子优先保护）
- 中心偏好（布局阶段）
